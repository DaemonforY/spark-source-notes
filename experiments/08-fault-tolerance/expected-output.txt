  [1] 第一次 count：
    Stage 0（attempt 0）: map，执行了 4 个 Task
    Stage 1（attempt 0）: count，执行了 2 个 Task
  [2] 杀掉 Executor 0（当前 Executor：0, 1），它上面的 Shuffle 输出随之丢失
  [3] 第二次 count：
    Stage 3（attempt 0）: count，执行了 2 个 Task

    Stage 3（attempt 1）: count，执行了 2 个 Task

        第二次 count 时 reduce Stage 先跑，读 Shuffle 报 FetchFailed，
        才去重算 map Stage——只重算丢失的分区，然后 reduce Stage 重试（attempt 1）
